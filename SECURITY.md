# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within GoRuntime Studio, please send an email to
denysskobalodev@gmail.com. All security vulnerabilities will be promptly addressed.

Please do not open public issues for security bugs.

## Security Best Practices for Contributors

- Never commit secrets, API keys, or credentials
- Keep dependencies up to date (`npm audit`)
- Follow the principle of least privilege in CI/CD configurations
